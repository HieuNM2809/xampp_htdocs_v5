PLAYING → PAUSED (Esc), PAUSED → PLAYING (Esc). PLAYING → GAME_OVER khi mất hết mạng. PLAYING → VICTORY khi đánh bại boss. GAME_OVER/VICTORY → MENU (Enter).

⏱ Loop chính (fixed timestep)

const FIXED_DT = 1/60; // 60 update/giây let acc = 0, last = performance.now(); function tick(now) { const frame = (now - last) / 1000; last = now; acc += Math.min(frame, 0.1); // giới hạn spike while (acc >= FIXED_DT) { if (state === 'PLAYING') update(FIXED_DT); acc -= FIXED_DT; } render(); // luôn vẽ (kể cả PAUSED, MENU...) requestAnimationFrame(tick); }

Tại sao fixed timestep? Physics deterministic — nhảy/va chạm cùng kết quả trên mọi máy. Tại sao tách update/render? Pause = ngừng update, vẫn render màn pause overlay.

🧩 Cấu trúc `Game` object

  • state — 'MENU' | 'PLAYING' | 'PAUSED' | 'GAME_OVER' | 'VICTORY'
  • currentLevel — index (0-3) của level đang chơi
  • player — đối tượng Player duy nhất
  • entities — mảng địch/item/block/fireball của level hiện tại
  • camera — { x, y } theo player
  • score, coins, lives, hiScore — số liệu HUD
  • input, audio, storage — tham chiếu module
