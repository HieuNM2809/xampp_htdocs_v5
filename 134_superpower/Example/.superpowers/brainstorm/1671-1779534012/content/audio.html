Phần 5/7 — Audio

WebAudio API tự sinh âm — không cần file .mp3/.wav

🎯 Tại sao dùng WebAudio synthesis

  • Không có file asset — repo gọn, không lo bản quyền nhạc Mario
  • Đậm chất chiptune — sóng vuông/sawtooth hợp với phong cách retro
  • Khởi tạo nhanh — không có loading time
  • Trade-off: nhạc nền đơn giản hơn (giai điệu ngắn lặp lại), không bằng nhạc thực

🎼 Nhạc nền

3 track tương ứng background của level:

  • overworld — vui, vừa nhanh (L1, L3)
  • underground — chậm hơn, âm sâu (L2)
  • castle — minor key, hồi hộp (L4)

Mỗi track là một mảng nốt + duration, scheduler dùng audioCtx.currentTime để xếp lịch chính xác, lặp vô hạn.

📐 API của audio.js

// src/audio.js export function createAudio() { const ctx = new AudioContext(); let musicVoice = null; let muted = false; return { unlock() { /* gọi 1 lần sau gesture đầu tiên */ }, play(sfxName) { /* phát SFX không chặn nhạc */ }, startMusic(trackName) { /* đổi track, fade in */ }, stopMusic() {}, setMuted(v) { muted = v; }, get isMuted() { return muted } }; }

🔇 Mute / autoplay

  • Trình duyệt chặn autoplay → phải gọi audio.unlock() sau lần ấn phím đầu tiên ở MENU
  • Phím M bật/tắt âm, lưu trạng thái vào localStorage
  • Nếu user mute, không khởi tạo AudioContext (tiết kiệm CPU)
