📋 Tóm tắt yêu cầu

Đây là những gì tôi đã nghe — đang sang phần chọn kiến trúc code

🎮 Gameplay

  • 2D side-scrolling cổ điển (kiểu Super Mario Bros)
  • 3-4 màn, lưu tiến trình giữa các màn
  • Desktop only — bàn phím (mũi tên/WASD + Space + Shift)

🎨 Đồ họa

  • Phong cách flat/cartoon hiện đại
  • Vẽ trực tiếp bằng Canvas (không sprite sheet)

⚙️ Stack

  • Vanilla JS + Canvas API
  • Không build step, mở index.html là chạy

✨ Tính năng

  • Power-up: nấm (Big Mario) + hoa lửa (bắn fireball)
  • Coin + điểm số (tự thêm — căn bản của Mario)
  • Âm thanh (SFX + nhạc) sinh bằng WebAudio (không cần asset)
  • High score lưu localStorage
  • Boss cuối game (Bowser-style)
  • Menu chính + pause + màn hình game over

⏭ Tiếp theo: chọn cách tổ chức code (xem terminal)
