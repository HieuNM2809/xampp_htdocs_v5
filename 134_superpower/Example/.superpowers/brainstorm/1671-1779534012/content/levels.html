Phần 4/7 — Levels

Mỗi level là một file .js export object dữ liệu thuần

📜 4 màn chơi

Level 1 — Overworld (Bầu trời xanh)

Dạy gameplay cơ bản: đi, nhảy, đạp Goomba, thu coin, ăn nấm. Không Koopa, không fireball.

Level 2 — Underground (Hang động)

Hành lang hẹp, nhiều brick-block, có Koopa. Coin xếp thành dòng. Giới thiệu fire flower.

Level 3 — Sky (Trên mây)

Platform nhỏ rải rác, nhảy chính xác, có vực. Mix Goomba bay (Goomba có cánh - biến thể) + Koopa thường.

Level 4 — Castle (Lâu đài, boss)

Hành lang tối, fire bar (bẫy lửa quay - bonus stretch), ít địch để dồn cho boss room cuối.

📦 Định dạng dữ liệu level

// src/levels/level1.js export default { name: '1-1 Overworld', width: 3200, // pixel width (camera scroll tới đây) height: 480, background: 'sky', // 'sky' | 'cave' | 'night' | 'castle' music: 'overworld', // tên track trong audio.js spawn: { x: 50, y: 300 }, // vị trí Mario xuất hiện blocks: [ { type: 'ground', x: 0, y: 416, w: 1024, h: 64 }, { type: 'ground', x: 1100, y: 416, w: 2100, h: 64 }, { type: 'brick', x: 320, y: 320 }, { type: 'qblock', x: 352, y: 320, contains: 'coin' }, { type: 'qblock', x: 384, y: 320, contains: 'mushroom' }, { type: 'pipe', x: 600, y: 352, h: 64 }, { type: 'flag', x: 3100, y: 200 } ], enemies: [ { type: 'goomba', x: 500, y: 384 }, { type: 'goomba', x: 800, y: 384 }, { type: 'goomba', x: 1500, y: 384 } ], coins: [ { x: 200, y: 350 }, { x: 240, y: 350 } // ... thêm coin ] }

Tại sao mảng object thay vì tilemap (mảng số)? Vì game flat/cartoon, không có tile sheet — block kích thước tùy ý. Dễ đọc, dễ chỉnh tay khi xây màn.
