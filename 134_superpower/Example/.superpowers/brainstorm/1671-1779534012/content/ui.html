🎯 Nguyên tắc

  • Tất cả UI vẽ trên canvas — không có DOM overlay → không có "lệch font" hay layout breakdown giữa các trình duyệt
  • HUD top bar luôn hiển thị khi PLAYING. Pause/GameOver là overlay đè lên scene đông cứng
  • Phím tắt chuẩn: Enter=xác nhận, Esc=pause/back, R=retry, Q=quit, M=mute
  • Font: dùng web-safe monospace + text-shadow giả pixel — không cần load font file

📐 API của ui.js

  • renderMenu(ctx, hiScore)
  • renderHUD(ctx, { score, coins, world, lives, time })
  • renderPauseOverlay(ctx)
  • renderGameOver(ctx, score, hiScore)
  • renderVictory(ctx, score, hiScore)

Mỗi hàm là pure: nhận ctx + dữ liệu, vẽ ra. Không giữ state.
