Phần 1/7 — Cấu trúc file

Mỗi module một trách nhiệm, ESM imports rõ ràng

📁 File tree

Example/ ├── index.html # <canvas> + nạp main.js ├── style.css # reset, layout canvas full screen ├── src/ │ ├── main.js # entry — khởi tạo Game, bind input │ ├── game.js # state machine + main loop (rAF) │ ├── input.js # keyboard → action state │ ├── renderer.js # camera, primitive draw helpers │ ├── physics.js # AABB collision, gravity, friction │ ├── audio.js # WebAudio: SFX + nhạc nền │ ├── storage.js # localStorage wrapper │ ├── ui.js # HUD, menu, pause, game over │ ├── entities/ │ │ ├── player.js # Mario (small / big / fire) │ │ ├── goomba.js # địch đi qua đi lại │ │ ├── koopa.js # rùa, đạp thành mai │ │ ├── block.js # ground, brick, ?-block │ │ ├── item.js # coin, mushroom, fire flower │ │ ├── fireball.js # projectile của Mario │ │ └── boss.js # Bowser-style cuối game │ └── levels/ │ ├── level1.js # dữ liệu màn 1 (overworld) │ ├── level2.js # dữ liệu màn 2 (underground) │ ├── level3.js # dữ liệu màn 3 (sky) │ └── level4.js # dữ liệu màn 4 (castle + boss) └── README.md # hướng dẫn chạy

🔀 Luồng phụ thuộc

main → game → { input, renderer, physics, audio, ui, storage, entities, levels }

Các module thấp tầng (input, renderer, physics, audio, storage) không import lẫn nhau — chỉ phơi API thuần. game.js là chỗ phối hợp tất cả.

📏 Quy tắc kích thước

  • Mỗi file mục tiêu <300 dòng
  • level data thuần JSON-ish (mảng objects), không có logic
  • entities tự render và tự update — không phụ thuộc renderer
