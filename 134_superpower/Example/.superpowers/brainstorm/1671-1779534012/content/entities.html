Phần 3/7 — Entities

Mỗi entity tự có update() + render() + getAABB()

📐 Interface chung của entity

// Mỗi entity là một class với 4 method này class Entity { constructor(x, y) { ... } update(dt, world) { // physics, AI, animation } render(ctx, camera) { // vẽ lên canvas } getAABB() { return { x, y, w, h } } onCollide(other) { // xử lý va chạm } get dead() { return this._dead } }

game.js loop qua mảng entities: gọi update, kiểm tra collision (AABB), gọi onCollide, lọc bỏ dead, rồi gọi render.

🦸 Player (Mario) — 3 hình thái

Small Mario
1 hit = chết
🍄 →
Big Mario
1 hit → small
🌸 →
Fire Mario
bắn fireball
  • state: 'small' | 'big' | 'fire'. Khi bị hit: fire→big→small→chết
  • Sau khi bị hit, bất tử 1.5s (nhấp nháy)
  • Press X (hoặc J) → bắn fireball (chỉ khi state='fire', tối đa 2 fireball cùng lúc)
  • Nhảy: ấn lâu nhảy cao hơn (variable-height jump)

👾 Enemies & Items

Goomba

Đi qua lại ngang, đổi chiều khi gặp tường/vực. Đạp lên → chết. Va vào sườn → mất 1 hit của Mario.

Koopa

Như Goomba nhưng đạp lần 1 → chui vào mai (entity mới: KoopaShell), đạp/đá vào mai → mai trượt và giết các địch khác trên đường.

Coin

Static, chạm vào → +100 điểm + SFX. Đủ 100 coin → +1 mạng.

Mushroom

Bật ra từ ?-block, di chuyển ngang (giống Goomba). Chạm → small→big.

Fire Flower

Bật ra từ ?-block, đứng yên. Chạm → big→fire (small→fire nếu đang small).

Fireball

Projectile Mario bắn. Nẩy mặt đất 2 lần rồi biến mất. Va địch → địch chết.

🧱 Blocks (entity tĩnh)

  • Ground — không tương tác, chỉ chặn
  • Brick — Big/Fire Mario đánh từ dưới → vỡ. Small Mario → bật lại
  • ?-block — đánh từ dưới → bật coin / mushroom / fire flower (định nghĩa trong level data)
  • Pipe — chặn, có thể đứng lên, decorative
  • Flag — chạm → hoàn thành level

👹 Boss (cuối Level 4)

  • Có HP = 5
  • Pattern: đi qua lại, thỉnh thoảng nhảy, thỉnh thoảng phun fireball ngang
  • Chỉ chịu sát thương từ fireball của Mario (không đạp được)
  • Hết HP → VICTORY state, lưu high score
