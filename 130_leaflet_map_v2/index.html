🗺️ Leaflet Map - Từ cơ bản đến nâng cao

Bộ ví dụ Leaflet.js thực tế theo kịch bản store locator (định vị cửa hàng). Mỗi file độc lập, dùng CDN, mở trực tiếp bằng trình duyệt là chạy.

  1. 01 - Bản đồ cơ bản CƠ BẢN Khởi tạo map, gắn tile OpenStreetMap, set view tới TP.HCM.
  2. 02 - Marker và Popup CƠ BẢN Thêm marker, popup khi click, tooltip khi hover.
  3. 03 - Hiển thị nhiều cửa hàng từ data CƠ BẢN Loop qua array, tự động fit bounds, popup chi tiết.
  4. 04 - Icon tùy chỉnh TRUNG BÌNH DivIcon (HTML/CSS) và Icon từ ảnh PNG.
  5. 05 - Gom nhóm marker (Cluster) TRUNG BÌNH Plugin MarkerCluster - cần khi có >50 marker.
  6. 06 - Tìm cửa hàng gần nhất TRUNG BÌNH Geolocation API + công thức Haversine tính khoảng cách.
  7. 07 - Chỉ đường (Routing) NÂNG CAO Plugin Leaflet Routing Machine + OSRM service miễn phí.
  8. 08 - GeoJSON vẽ vùng/quận NÂNG CAO Vẽ polygon, đổi màu theo dữ liệu (choropleth), interactive.
  9. 09 - Tìm kiếm địa chỉ (Geocoding) NÂNG CAO Search box - convert địa chỉ sang toạ độ qua Nominatim.
  10. 10 - Bản đồ nhiệt (Heatmap) NÂNG CAO Trực quan mật độ - phù hợp phân tích vùng mua sắm.

💡 Mẹo: Mở DevTools (F12) → tab Console để xem các log mẫu trong từng ví dụ.
📦 Tất cả thư viện đều load từ CDN, không cần cài đặt gì.
